# 급여 계산 정확도 — 무엇이 확정이고 무엇이 아닌가 (2026-09-12)

사장님 지시: "노무사가 필요없을 정도로 우리 앱을 이용만 해도 제대로 된 급여를 줄 수 있게."

이 문서는 **어디까지 우리가 책임질 수 있는지**를 적는다. 급여는 틀리면 임금체불이 되므로
"거의 맞다"를 "맞다"라고 말하지 않는다.

## 종전 계산의 문제

`packages/shared/src/finance/hiring-cost.ts` 는 **채용 비용 견적**이었지 급여 계산이 아니었다.

| 문제 | 종전 | 결과 |
|---|---|---|
| 소득세 | 과세표준 × **3% 정률** | 월 200만원에서 실제의 10배 넘게 과다 |
| 근태 | 반영 없음 (계약 시간만) | 결근·연장·야간이 급여에 안 들어감 |
| 주휴 | 월 단위 근사 | 개근 요건·8시간 상한 미판정 |
| 가산수당 | 없음 | 승인된 연장·야간·휴일이 지급에 반영 안 됨 |
| 국민연금 | 상·하한 없음 | 고소득자 과다, 저소득자 과소 |
| 5인 기준선 | 없음 | 5인 미만인데 가산을 주거나, 5인 이상인데 안 줌 |
| 임금명세서 | 없음 | 근기법 §48② 교부 의무 미이행 (과태료 500만원 이하) |

## 지금 계산

`packages/shared/src/payroll/` (웹 SSOT) + `apps/ios/Sources/FoundOneCore/Payroll.swift` (미러).

### 확정 — 법정 계산식 그대로

- **통상시급**: 시급제는 시급, 월급제는 월급 ÷ 209시간(주 40시간 기준).
- **주휴수당**: 주 단위 개근 판정. (주 소정 ÷ 40) × 8, 8시간 상한, 15시간 미만 미발생.
  월급제는 209시간에 이미 포함돼 **두 번 주지 않는다**.
- **연장·야간·휴일**: 5인 이상만 가산. 연장 1.5배, 야간 1.5배, 휴일 8h 이내 1.5배 / 초과 2.0배.
  5인 미만은 가산 없이 통상임금만 지급하고 그 사실을 화면에 적는다.
- **4대보험**: 2026 고시 요율. 국민연금 기준소득월액 상·하한(41만~659만) 적용.
  주 15시간 미만은 연금·건보 제외. 65세 이후 신규 고용은 실업급여 제외. 두루누리 80% 반영.
- **최저임금 판정**: 통상시급 기준 — 월급제도 환산해서 본다.

### 추정 — 확정이라고 말하지 않는다

- **소득세·지방소득세**: 국세청 간이세액표의 산식 구조(근로소득공제 → 인적공제 → 연금보험료공제
  → 특별공제 간주액 → 기본세율 → 근로소득세액공제)를 옮긴 추정.
  **법적 기준은 홈택스의 간이세액표**이며 수천 원 차이가 날 수 있다. 화면에 그대로 적고 조회를 안내한다.
- **산재보험료**: 업종 기본값(도소매·음식·숙박 0.8% + 출퇴근재해 0.06%).
  실제 요율은 근로복지공단 고지서 값이 정답 — 입력하면 확정으로 바뀐다.
- **주휴수당(출결 기록이 없을 때)**: 계약 시간으로 추정. 기록이 있으면 확정.

| 사장 — 임금명세서 (iOS `PayslipSheet` / 웹 `PayslipView`) | 법정 기재사항 전부 + 공유(카톡·문자) | 보임 |
| 직원 — 권리·급여 탭 | 내 지급·공제·실지급 + 「임금명세서 보기」 | **숨김** |

직원 화면에서 사업주 부담을 숨기는 이유: 명세서 기재사항이 아니다(근기법 §48② 는 지급·공제만 요구).
성명 칸에는 **본인 이름**(auth user_metadata.name)을 넣는다 — 상호를 넣으면 "근로자 특정" 기재가 틀린다.

## 그래도 노무사가 필요한 것

앱이 대신할 수 없는 것을 분명히 해 둔다. 이걸 숨기면 사장님이 다친다.

1. **상시 근로자 수 산정** — 단순 인원수가 아니라 산정 기간의 연인원으로 계산한다.
   5인 경계에 있는 사업장은 가산수당·연차 의무가 뒤집히므로 확인이 필요하다.
2. **통상임금의 범위** — 정기상여금·각종 수당이 통상임금에 들어가는지는 다툼이 많다
   (2024-12 대법원 전원합의체로 '고정성' 요건이 폐지됐다).
3. **포괄임금제** — 수당을 미리 얹은 계약은 유효성·정산 방식이 사안마다 다르다.
4. **연말정산** — 월 원천징수는 선납이고, 실제 세액은 연말정산에서 확정된다.
5. **퇴직금 확정액** — 퇴직 전 3개월 평균임금 기준. 우리는 월 적립 권장액만 낸다.

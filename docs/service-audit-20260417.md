# Found.One 서비스 종합 진단 보고서

**작성일**: 2026-04-17
**목적**: 전체 기능·효과·로드맵을 해부하고, "창업자를 진짜 살리는 서비스"가 되기 위한 개선 방향 도출
**요약 평가**: MVP 완성도 80/100 — 구조는 탁월, 하지만 "창업자의 진짜 고통"은 아직 덜 건드림

---

## I. 서비스 본질 재정의

### 약속된 비전
> "긴 체크리스트 대신, 지금 정해야 할 것 하나만 또렷하게"

### 3대 설계 원칙
1. **Roadmap-first** — 단계별 선형 흐름, 인지 부하 최소화
2. **Logic-before-AI** — 규칙 엔진 우선, AI는 보조
3. **Freshness-aware** — 모든 정보에 검증일·신뢰도·출처 첨부

### 3대 타깃 페르소나
| 페르소나 | 여정 진입점 | 핵심 니즈 |
|---|---|---|
| 예비 창업자 | Manual Roadmap | "업종·예산·입지를 어떻게 정하지?" |
| 아이디어만 있는 사람 | AI Auto Roadmap | "내 상황에 맞는 플랜 자동 생성" |
| 운영 중 점주 | Already Running | "매출·비용·재고·직원 한눈에" |

## II. 서비스 기능 전체 조감도

### A. 로드맵 (26단계 × 5경로)

```
공통 → [업종] → [창업형태] → [사업모델] → [예산] → [상권] → [계약]
        │
        ├── STARTUP (7): 문제정의 → 고객발견 → MVP → 법인 → GTM → 펀딩 → 성장엔진
        ├── OFFLINE (7): 공급처 → 운영세팅(POS/배달/SNS) → 소프트오픈 → 오픈 → 세무 → 대출
        ├── ONLINE (5):  플랫폼선택 → 스토어세팅 → 소싱 → 마케팅 → 등록
        └── FRANCHISE (4): 본사신청 → 공급망 → 오픈 → 운영
        │
        └── SHARED-TAIL (4): 오픈당일 → 첫달점검 → 세무가이드 → 추가자금
```

**강점**
- 5개 경로가 실제 한국 창업 시장 현실과 부합 (스타트업·독립·프랜차이즈·온라인)
- 단계별 산출물(`decisionMap`, `taskMap`, `aiRoadmapResult`)이 TypeScript 타입으로 명시 → 제품팀이 블랙박스 없이 수정 가능
- 공정위 가맹사업 통계·카카오맵·세마스·국세청 API 등 한국 특화 데이터 연계

**진짜 약점 (창업자 관점)**
- 🚨 **운영자본금 계산 부재** — 초기 3개월 적자 완충금이 예산에 녹아있지 않음
- 🚨 **"첫 손님 확보" 전략 부재** — 오픈 직전까지만 가이드, 오픈 후 "사람이 올까?"는 공백
- 🚨 **실패·피벗 플레이북 없음** — "이 상권이 틀렸다면?", "업종을 바꿔야 한다면?" → 돌아가는 길이 코드에 없음
- **가맹점주 실제 리뷰 없음** — 공정위 공식 데이터만 신뢰 (데이터 신선도·편향 메타 부재)
- **네트워킹 부재** — 법무사·세무사·선배 창업자 연결 통로 없음

## III. 효과 분석 — 창업자가 얻는 것 vs 얻지 못하는 것

### ✅ Found.One이 실제로 해결해주는 것
1. **인지 부하 제거** — "지금 뭘 해야 하지?"에 대한 즉답
2. **한국 로컬 지식 격차 해소** — 공정위·세무·부동산 데이터를 UI로 통합
3. **재무 지표 자동 계산** — BEP·런웨이·원가율을 손으로 계산 안 해도 됨
4. **매일 코칭** — MorningBriefing·NotificationCenter로 피드백 루프

### ❌ 아직 해결 못 하는 것 (창업 실패의 진짜 원인들)

| 실패 원인 | 업계 통계 | Found.One 현재 대응 |
|---|---|---|
| 수요 없는 제품 | 스타트업 42% | Customer Discovery 단계 ✅ 있지만 오프라인 업종에도 적용 안 됨 |
| 현금 고갈 | 스몰비즈 82% | CashFlowForecast ✅ 있지만 7일만 |
| 첫 고객 확보 실패 | — | ❌ 공백 |

| 법률·계약 함정 | — | AI 계약서 분석 일부만 |
| 마케팅 과소 투자 | — | Marketing 탭 ✅ 있지만 ROI 미연결 |
| 멘탈 번아웃 | — | ❌ 완전 공백 |

## IV. "진짜 최고의 창업 파트너"가 되기 위해 필요한 것들

창업자 관점에서 우선순위를 매긴 제안. 각 항목은 **영향 × 구현 난이도** 기준.

### 🔥 P0 — 즉시 추가 (4주 내, 제품 정체성 방어)

#### 1. 운영자본금 & 첫 3개월 생존 시뮬레이터
**왜**: 예산 단계가 "창업비용"만 묻고 "첫 3개월 적자 완충"을 안 물음 → 오픈 후 2개월 만에 폐업하는 패턴 반복
**어떻게**:
- Budget 단계에 "초기 운영자본금" 별도 입력
- "월 예상 적자 × 3~6개월" 자동 권장
- ForecastCard에 "자본금 소진 예상월" 표시 + 한계 넘으면 빨간 경고

#### 2. 첫 고객 확보 플레이북 (Pre-Launch 직후 공백 메우기)
**왜**: SHARED-TAIL의 Pre-Launch Final 이후 → First Month Check까지의 1~30일이 가장 힘든데 가이드가 비어있음
**어떻게**:
- 업종별 "첫 100명 확보" 체크리스트 (오프라인: 동네 전단, 리뷰이벤트 / 온라인: 초대코드, 인플루언서 / 스타트업: ProductHunt, HN)
- 초대/쿠폰 코드 관리 위젯 (발급 → 추적 → 컨버전)
- 실제 업종별 "첫 주 매출 분포" 벤치마크 → "당신은 상위 30%입니다"

#### 3. What-If 시뮬레이터 (대시보드 최강 무기화)
**왜**: 현재 대시보드는 "진단"에서 멈춤 → "그래서 뭘 바꾸지?"에 답 못함
**어떻게**:
- PLHeroCard / CostStructureCard에 "시뮬" 버튼
- 슬라이더로 인건비·임대료·객단가·고객수 변경 → 월 순익·런웨이·BEP 실시간 재계산
- "인건비 50만↓ 시 런웨이 +0.7개월" 같은 구체적 수치

#### 4. 데이터 Export (CSV/Excel/PDF)
**왜**: 세무사·은행·투자자에게 보여줘야 할 때 복붙 지옥. 이미 memory에 high-priority로 기록됨.
**어떻게**:
- 매출·비용·재고·직원·P&L 각각 CSV 다운로드
- 월간 PDF 리포트 (WeeklyReport 확장형)

### 🟡 P1 — 2~8주 (경쟁 해자 구축)

#### 5. 피벗·탈출로 가이드
- 상권이 잘못됐을 때, 업종이 안 맞을 때, 돈이 떨어졌을 때의 "돌아가는 길"
- 폐업 시 부채탕감·세무정리 절차
- 업종 전환 시 이미 투입한 비용 회수 계산기

#### 6. AI 액션 피드백 루프
- "이 조언 실행했음 / 안 함" 버튼 → 다음 조언 품질 개선
- 12주 데이터 축적 시 개인화 정확도 급상승

#### 7. 알림 임계값 사용자 설정
- NotificationCenter 스팸 방지
- "일매출 30% 하락 시만", "재고 X일치 이하만" 등 개인화

#### 8. 멘토·전문가 연결 디렉토리
- 세무사·법무사·PB·선배창업자 목록 (지역·업종별)
- 건당 상담 연결 (수익 모델도 됨)

#### 9. 벤치마크 사례 확대 (현재 상황당 2개 → 10개)
- 같은 업종·상권·매출대의 선배 사례 DB 구축
- "당신 같은 상황의 A씨는 6개월 후 어떻게 됐는가" 이야기

### 🟢 P2 — 8~16주 (플랫폼 확장)

#### 10. 협업·역할 기반 접근
- 오너·매니저·회계사 각각 다른 뷰
- 한 가게 여러 사용자 (이미 `store_invites`, `store_members` 테이블 준비됨)

#### 11. A/B 테스트 추적기
- "메뉴 A로 바꾼 후 7일 매출" 자동 비교
- 객단가 실험, 가격 테스트, 마케팅 채널 실험

#### 12. 메뉴·상품별 객단가 분해
- SalesBreakdownCard 확장 — "세트메뉴가 객단가 끌어올리는가?"
- ABC 분류로 재고 우선순위

#### 13. 초기 고객 확보 자동화
- 네이버플레이스·인스타·카카오채널 연동 → 매크로성 포스팅 지원
- 리뷰 요청 자동 메시지

### 🔮 P3 — 16주+ (장기 비전)

#### 14. 동네 벤치마크 네트워크
- 같은 상권 익명 데이터 공유 → "이 지역 평균 매출 대비 당신 위치"
- 임대료 협상 근거 제공

#### 15. 멘탈/번아웃 케어
- 경영자 스트레스 체크인 (주 1회 간단 서베이)
- 번아웃 신호 감지 시 휴식·위임 권장

#### 16. 머신러닝 기반 예측 고도화
- 시계열 분해(Trend + Seasonal + Cyclical)
- "당신의 매장은 매월 15~20일 스파이크"
- MAPE 10% 이내 목표

#### 17. 폐업·출구 데이터
- 업종별 평균 생존 개월·폐업 사유 데이터화
- "비관적 시나리오"도 있는 그대로 보여주기 (현재는 긍정편향)

## V. 전략적 제언 — "한국판 YC 온보딩"을 넘어서

### 제품 정체성 재정의

현재: **"예비 창업자를 위한 로드맵"**
→ 제안: **"매일 의존하는 경영 파트너"**

memory/user_vision.md와 완전히 부합. 다만 이 비전을 달성하려면:

1. **"오픈 전"보다 "오픈 후 1년"에 더 많은 가치를 만들어야 함**
   - 현재는 26단계 중 오픈 이전이 22개, 이후가 4개 (Shared-tail)
   - 이 비율을 역전시켜야 함 — 오픈 후 매주·매월 새로운 가치 제공

2. **"정보 제공"에서 "행동 유도"로**
   - 현재도 AI 코칭·알림·체크리스트 있음
   - 한 단계 더: "버튼 한 번으로 실행" (예: 인스타 포스팅, 재주문, 쿠폰 발급)

3. **"개인 도구"에서 "네트워크 효과"로**
   - 같은 동네·같은 업종 창업자들의 익명 벤치마크
   - 선배→후배 멘토 매칭
   - B2B 공급처 평가 집단지성

### 수익 모델 (현재 코드에 없음)

가능한 구조:
- **Free**: 로드맵·기본 대시보드 (고객 유입용)
- **Pro (월 ~3만)**: What-If 시뮬, Export, AI 무제한, 협업 3인
- **Business (월 ~9만)**: 다점포, 멘토 매칭, 정부지원사업 대행
- **B2B**: 지자체 창업지원센터, 프랜차이즈 본사 — 가맹점주 패키지

### 최우선 3가지 (만약 1달 동안 딱 3개만 한다면)

1. **운영자본금 시뮬레이터 + ForecastCard 런웨이 강화** → 폐업 예방 핵심
2. **첫 100명 고객 확보 플레이북 + 쿠폰/초대 관리** → 오픈 후 죽음의 계곡 돌파
3. **What-If 시뮬레이터** → "진단"에서 "의사결정"으로 진화

## 2. 실무에서 실제로 막히는 지점 — "정보 부족"이 아니라 "판단·검사·계산"

조사한 커뮤니티·FAQ를 보면 창업자가 막히는 곳은 정보가 없어서가 아니다. 정보는 흩어져 있고, **자기 상황에 대입해 판단**해야 하는 곳에서 막힌다.

1. **채널 선택은 다차원 판단**: 비용(정액 vs 건당) × 반환 항목(성별·내외국인) × 테스트 가능 여부 × 계약 기간 × 보증보험 × 결제 병행 여부. 문서 3~4개를 교차해야 한다. → 조건을 넣으면 결과가 나오는 **선택기**가 필요.
2. **PG 심사는 사이트를 "눈으로" 보는 검사**: 심사관이 URL을 열어 7항목·상품·약관·환불을 확인한다. 반려 1건당 14일+. → 제출 전에 **같은 검사를 기계가 먼저** 하면 반려가 0이 된다.
3. **마감은 날짜 계산 + 잊지 않기**: D+30(위치정보), 7일 전 고지, 카드사 심사 7~14영업일 중 상품 변경 금지 기간. → 계산기 + 대시보드 마감 카드.
4. **서류 요청 메일은 외국어**: 사본/원본/증명/인감/실제소유자 확인서/마스킹. → 메일을 붙여넣으면 **용어별로 '어디서 어떤 형식으로'** 를 붙여주는 해석기.
5. **절차 의존성**: 사업자등록 → (소상공인확인서) → 위치정보 신고, 법적 페이지 → PG 심사, PG 계약 → 통신판매업 신고(유료 시), 본인확인만 신청 시 APK로 심사 가능. → 내 상태(등록 여부·URL 검사 결과·출시 상태)를 반영한 **의존 그래프**.
6. **비용 함정은 콘솔 기본값**: '전자결제 신청' 메뉴 이름, 결제수단 기본 신용카드 → 33만원 화면. → 선택기 결과에 "결제 안 받음"이면 **클릭 단위 경고**를 붙인다.

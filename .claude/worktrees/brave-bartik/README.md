# build.up

Roadmap-first startup companion for web and mobile.

## Workspaces

- `apps/web`: Next.js web experience
- `apps/mobile`: Expo app experience
- `packages/shared`: shared domain types and workflow logic
- `packages/config`: shared configuration

## Product Principles

- Logic-first workflow progression
- AI only where explanation or reasoning is needed
- Freshness and source metadata on user-facing knowledge

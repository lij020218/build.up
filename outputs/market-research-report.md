## 1. 시장 규모 및 수요

### 1.1 한국 소상공인/자영업 현황

| 지표 | 수치 | 출처 |
|------|------|------|
| 자영업자 수 (2025) | 약 561만 명 (취업자의 ~20%) | e-나라지표 |
| 소상공인 사업체 수 | 약 613만 개 (2024 기준) | 소상공인실태조사 |
| 소상공인 종사자 수 | 약 961만 명 | 소상공인실태조사 |
| OECD 자영업 비율 평균 | 15.6% (한국은 약 20%로 높은 편) | OECD |

### 1.2 연간 창업기업 수 추이

| 연도 | 창업기업 수 | 전년 대비 |
|------|-----------|----------|
| 2020 | 148만 4,667개 | +15.5% (코로나 특수) |
| 2021 | 141만 7,973개 | -4.5% |
| 2022 | 131만 7,479개 | -7.1% |
| 2023 | 123만 8,617개 | -6.0% |
| 2024 | 118만 2,905개 | -4.5% |

2024년 기준 연간 약 **118만 개**의 신규 창업이 발생하며, 3고(고금리, 고환율, 고물가) 여파로 감소세이나 여전히 연 100만 건 이상의 대규모 시장이다.

### 1.3 폐업률 및 생존율 -- 핵심 문제

| 지표 | 수치 |
|------|------|
| 2024년 폐업 사업자 수 | **100만 8,282명** (사상 최초 100만 명 돌파) |
| 1년 생존율 | 약 78% (1년 내 폐업 22%) |
| 3년 생존율 (100대 생활업종) | **52.3%** |
| 5년 생존율 | **40.2%** |
| 폐업 시 평균 부채 | 1억 236만 원 |
| 평균 영업 기간 (폐업자) | 6.5년 |

**핵심 통찰:** 창업 자영업자 10곳 중 6곳은 5년 안에 폐업하며, 40%는 창업 3년도 못 넘기고 폐업한다. 이는 체계적인 창업 준비 및 경영 관리 도구의 **절대적 필요성**을 보여준다.

### 1.4 창업 비용

| 항목 | 금액 (2024 기준) |
|------|-----------------|
| 평균 총 창업비용 | 8,300만 원 |
| 본인 부담분 | 5,900만 원 (전년 6,400만 원에서 감소) |
| 평균 창업 준비 기간 | 11.8개월 |

### 1.5 디지털 도구 수요

- 디지털/스마트 기술 활용 소상공인 비중: **27.2%** (전년 대비 9.2%p 증가)
- 주요 활용 기술: 온라인 판로(49.2%), 스마트 주문/결제(41.8%), 디지털 광고(15.4%)
- **72.8%의 소상공인이 아직 디지털 도구를 활용하지 못하고 있음** -- 거대한 미개척 시장

### 1.6 시장 규모 추정

**글로벌 SMB 소프트웨어 시장:**
- 2025년: USD 745.4억 (약 100조 원)
- 2026년: USD 801.5억 예상
- AI 기반 소기업 관리 플랫폼 시장: 2025년 USD 6억 → 2033년 USD 48.9억 (CAGR 30%)
- 아시아-태평양 지역은 CAGR 32%로 가장 빠른 성장 예상

**한국 타겟 시장 규모 추정:**
- 소상공인 613만 개 사업체 x 디지털 도구 미활용 72.8% = **약 446만 개 잠재 고객**
- 월 1~2만 원 구독 가정 시 연간 TAM: **약 5,000억~1조 원 규모**

### 2.2 공공 플랫폼

| 서비스 | 핵심 기능 | 사용자 현황 |
|--------|----------|------------|
| **소상공인 365** | 빅데이터 상권분석, 경영진단, 정책정보 | 2025.1 런칭 후 146만 건 이용 (만족도 80%) |
| **K-Startup** | 창업지원사업 공고, 멘토링 | 예비창업자 대상 정부 포털 |
| **마이프차** | 프랜차이즈 정보 비교 | 가맹점 창업 준비 특화 |

### 2.3 핵심 관찰

1. **"창업 준비 단계"에 특화된 종합 플랫폼이 없다.** 대부분의 서비스는 이미 사업을 시작한 사업자를 대상으로 한다.
2. 캐시노트가 "소상공인 국민앱"으로 가장 강력한 포지션을 차지하고 있으나, 매출 관리/운영 최적화에 집중하며 창업 전 단계는 미지원.
3. 상권분석은 소상공인365 등 무료 공공서비스가 있으나, 단순 데이터 제공에 그치며 **의사결정 가이드**가 부재.
4. 프랜차이즈 비교, 인허가 가이드, 인테리어 가이드, 벤더 추천 등을 **통합**하는 서비스는 사실상 존재하지 않는다.

## 3. 글로벌 경쟁사 분석

### 3.1 주요 글로벌 플랫폼

| 서비스 | 핵심 영역 | 사용자/매출 | 특징 |
|--------|----------|-----------|------|
| **Shopify** | 이커머스 + POS | 수백만 가맹점 | 온라인 판매 생태계 최강, 하지만 창업 준비 도구 아님 |
| **Square** | POS + 결제 + 금융 | 수백만 가맹점 | 무료~$149/월, 결제 중심 올인원 |
| **Toast** | 외식업 특화 POS | 외식업 특화 | 테이블 주문, 주방 디스플레이 등 레스토랑 전문 |
| **LegalZoom** | 법인 설립, 컴플라이언스 | 196만 구독, 매출 $7.5억 (2025) | 법적 절차에 특화, 경영 관리 없음 |
| **Gusto** | HR, 급여, 복리후생 | 40만+ 기업 | 급여/인사 전문, 소기업 대상 |
| **FreshBooks** | 회계, 인보이스 | 서비스업 타겟 | 프리랜서/소기업 회계 |
| **Wave** | 무료 회계 | 예산 제한적 스타트업 | 무료 회계 도구 |
| **Homebase** | 직원 스케줄링, 근태관리 | 시간제 직원 매장 | 시프트 관리 특화 |
| **HoneyBook** | 프로젝트 관리, 인보이스, CRM | 서비스 사업자 | 올인원이나 서비스업 특화 |
| **Venturekit** | AI 사업계획서, 재무예측, 시장조사 | 신규 서비스 | 창업 준비에 가장 가까운 글로벌 도구 |

### 3.2 글로벌 시장 핵심 관찰

1. **"창업 준비부터 운영까지" 전 주기를 커버하는 올인원 플랫폼은 글로벌에도 사실상 존재하지 않는다.** 이는 build.up의 가장 큰 기회이다.
2. 글로벌 서비스들은 각자 특정 영역(결제, 회계, HR, 법률)에 특화되어 있고, 사용자는 여러 도구를 조합해서 사용한다.
3. LegalZoom이 "법인 설립 → 컴플라이언스 구독"으로 전환한 모델은 build.up의 "창업 준비 → 운영 관리" 전환 모델과 유사한 비즈니스 로직을 보여준다.
4. AI 기반 창업 도구(Venturekit 등)가 등장하고 있으나, 한국 소상공인에 특화된 서비스는 부재.

## 4. build.up의 차별점

### 4.1 기능 대비 경쟁사 매트릭스

| 기능 | build.up | 캐시노트 | 소상공인365 | 마이프차 | LegalZoom | Shopify |
|------|----------|---------|-----------|---------|-----------|---------|
| 창업 로드맵 (단계별 가이드) | **O** | X | X (데이터만) | X | X | X |
| 프랜차이즈 비교 분석 | **O** | X | X | **O** | X | X |
| 상권/입지 분석 | **O** | 부분 | **O** | 부분 | X | X |
| 인허가/법률 가이드 | **O** | X | 정책정보 | X | **O** (미국) | X |
| 인테리어 가이드 | **O** | X | X | X | X | X |
| 벤더/공급사 추천 | **O** | 캐시노트마켓 | X | X | X | X |
| 재무 시뮬레이션 | **O** | 매출분석 | 부분 | X | X | X |
| 운영 대시보드 | **O** | **O** | 경영진단 | X | X | **O** |
| AI 기반 분석/추천 | **O** | **O** (캐시니) | X | X | X | **O** |

### 4.2 build.up만의 고유 가치

1. **전 주기 커버리지**: 창업 준비(아이디어 → 업종선정 → 입지 → 인허가 → 인테리어 → 오픈) → 운영관리까지 단일 플랫폼
2. **한국 소상공인 특화**: 한국 법제도, 상권 데이터, 프랜차이즈 정보, 한국어 AI에 완전히 최적화
3. **의사결정 도우미**: 단순 데이터 제공이 아닌, "무엇을 해야 하는지" 가이드 제공
4. **업종별 맞춤 로드맵**: 외식업, 카페, 소매업 등 업종 특성에 맞는 구체적 가이드

### 4.3 build.up에 없는 것 (경쟁사 대비 갭)

| 경쟁사 기능 | 설명 | 우선순위 |
|------------|------|---------|
| 실시간 POS 매출 연동 | 캐시노트의 핵심 - 카드사/POS 자동 연동 | 높음 (데이터 파트너십 필요) |
| 결제/정산 기능 | 토스비즈니스, Square의 핵심 | 중간 (별도 파트너십) |
| 세무/회계 자동화 | 머니핀, 자비스의 핵심 | 중간 (연동으로 해결 가능) |
| 직원 HR 관리 | 플렉스, 뉴플로이의 핵심 | 낮음 (초기 소상공인에 덜 필요) |
| 배달/주문 관리 | 배민사장님의 핵심 | 낮음 (플랫폼 종속 기능) |
| 마케팅/광고 집행 | 네이버, 당근비즈니스 | 중간 (가이드로 커버 가능) |

## 5. 사용자 페인포인트

### 5.1 창업 전 단계 어려움

| 페인포인트 | 비율/근거 |
|-----------|----------|
| 정보 과부하 + 체계 부재 | 어디서부터 시작해야 할지 모름 |
| 상권 분석의 어려움 | 데이터는 있으나 해석/판단 어려움 |
| 인허가 절차 복잡성 | 업종별로 다른 복잡한 규제 |
| 창업 비용 예측 어려움 | 평균 8,300만 원이나 업종/지역별 편차 큼 |
| 프랜차이즈 vs 독립창업 판단 | 객관적 비교 정보 부족 |
| 인테리어/시설 업체 선정 | 신뢰할 수 있는 업체 정보 부재 |

### 5.2 운영 중 경영 애로사항 (2024-2025 설문 기반)

| 애로사항 | 비율 |
|---------|------|
| 경쟁 심화 (유사 업종 과당 경쟁) | 61.0% |
| 원재료비 상승 | 49.6% |
| 내수 부진에 따른 고객 감소 | 52.2% |
| 인건비 상승 (최저임금 10,030원) | 49.4% |
| 임대료/관리비 등 고정비 상승 | 44.6% |
| 온라인 플랫폼 수수료/광고비 | 35.6% (숙박/음식점) |
| 디지털 기술 활용 어려움 | 72.8%가 미활용 |

### 5.3 폐업 원인 분석 (중소기업중앙회 2025 조사)

- 수익성 악화 및 매출 부진이 주된 폐업 사유
- 창업 전 충분한 **상권 분석, 업종 적합성 검증, 수익 구조 검증**을 하지 않은 경우 실패 확률이 크게 높아짐
- 폐업까지 영업기간 3년 미만 비중: **약 40%**
- 폐업 비용: 2,000만 원 이상 필요

**핵심 시사점:** 폐업의 상당수는 **창업 준비 단계에서의 불충분한 검증**에서 비롯된다. build.up의 창업 준비 가이드가 이 문제를 직접적으로 해결할 수 있다.

## 6. 시장 트렌드 2025-2026

### 6.1 AI 통합 가속화

- 글로벌 SMB의 AI 도입률: 2024년 40% → 2025년 **58%+**
- AI 기반 소기업 관리 플랫폼 시장: 2025년 $6억 → 2033년 $48.9억 (**CAGR 30%**)
- 캐시노트도 AI 비서 '캐시니'를 출시하며 AI 경쟁 본격화
- AI 도입 매장 매출 10~40% 증가 사례 보고 (광주 실증사업)

### 6.2 정부 디지털화 정책 강화

- **2026년 소상공인 예산: 역대 최대 5.4조 원**
- AI/디지털 전환을 축으로 경영회복과 지속성장 지원
- 스마트 상점 기술보급 사업: 도입 비용의 50~80% 정부 지원
- 소상공인365 정식 런칭 (2025.1) -- 정부가 직접 디지털 경영지원 플랫폼 운영
- K-비대면바우처 사업으로 디지털 도구 90% 지원

### 6.3 MZ세대 창업 트렌드

- 실용세대: 성비를 중요시하고 브랜딩을 필수로 인식
- 낮은 원가/적은 인건비/수월한 운영 방식 선호
- 디지털 네이티브로서 앱 기반 도구 활용에 거부감 없음
- 전략적 창업 접근: 데이터 기반 의사결정 선호

### 6.4 시장 구조 변화

- 연간 100만 명 폐업 시대 진입 (2024년 최초 돌파)
- KDI 추산 적정 자영업 비율 16% → 현재 20%에서 약 100만 개 사업체 구조조정 예상
- "디지털 격차 = 생존 격차" 공식 고착화
- 플랫폼 수수료 부담 증가로 자체 관리 도구 수요 증가

## 7. 전략적 시사점

### 7.1 기회 요약

| 기회 | 근거 |
|------|------|
| **빈 시장 (Blue Ocean)** | "창업 준비 → 운영"을 잇는 올인원 플랫폼이 국내외 모두 부재 |
| **거대한 TAM** | 613만 소상공인 + 연 118만 신규 창업 |
| **절박한 수요** | 3년 내 폐업 40%, 대부분 준비 부족에서 기인 |
| **디지털 전환 가속** | 정부 5.4조 예산, AI 도입 급증, MZ세대 창업 증가 |
| **정부 지원 활용 가능** | K-비대면바우처, 스마트상점 보급 사업 등으로 고객 획득 비용 절감 가능 |

### 7.2 위협 및 리스크

| 위협 | 대응 방안 |
|------|----------|
| 캐시노트의 시장 지배력 (140만 사업장) | build.up은 "창업 전" 단계로 진입, 캐시노트는 "운영 중" 타겟 -- 직접 경쟁 아닌 보완 관계 구축 가능 |
| 소상공인365 무료 서비스 | 공공 서비스는 데이터 제공에 그침, build.up은 "실행 가능한 가이드" 차별화 |
| 소상공인의 유료 도구 저항 | 프리미엄 모델 + 정부 바우처 활용으로 진입 장벽 낮춤 |
| 경기 침체로 창업 감소 | 오히려 "실패를 줄이는 도구"로서 가치 증가 |

### 7.3 권장 전략

1. **포지셔닝**: "창업 성공률을 높이는 AI 파트너" -- 캐시노트와 경쟁이 아닌, 캐시노트 이전 단계를 장악
2. **수익 모델**: 기본 무료 + 프리미엄 구독 (월 1~2만 원) + 벤더/프랜차이즈 파트너십 수수료
3. **초기 타겟**: 예비 창업자 + 창업 1년 미만 사업자 (연 118만 + 기존 풀)
4. **데이터 해자**: 업종별 창업 로드맵, 인허가 DB, 벤더 DB, 상권 분석 노하우 축적
5. **확장 경로**: 창업 준비 → 운영 대시보드 → POS/회계 연동 → 금융 서비스

### 7.4 build.up의 시장 적합성 (Product-Market Fit) 평가

**강한 PMF 신호:**
- 명확한 시장 공백: 창업 준비 올인원 도구 부재
- 대규모 고통점: 폐업 40%가 준비 부족에서 기인
- 정부 정책 순풍: 디지털 전환 예산 역대 최대
- 기술 타이밍: AI 기반 도구 수용도 급증

**검증 필요 사항:**
- 예비 창업자의 유료 구독 전환율
- 창업 완료 후 운영 도구로의 전환율 (LTV 핵심)
- 실제 사용자의 창업 성공률 개선 효과 측정

## 1. 서비스별 상세 조사

### 1.1 캐시노트 (CashNote) — 한국신용데이터(KCD)

**핵심 기능:**
- **매출 통합 조회**: 카드사별 정산 주기와 수수료를 자동 계산, 일별/주별/월별 매출 대시보드 제공
- **간편 장부**: 사업자 거래내역을 자동으로 분류하여 세금 신고용 장부 생성
- **AI 비서 '캐시니'** (2025.06 출시): 매출·입금 예정액 예상, 상권 비교·리뷰 분석, 맥락형 응답 제공
- **데이터랩**: 전국 170만 사업장 데이터 기반 상권분석, AI 경영진단 리포트
- **B2B 구매**: 식자재 등 사업 운영에 필요한 물품 직접 구매
- **POS 연동**: POS 매출 데이터 통합 분석
- **배달앱 리뷰 통합관리**: 배민/요기요 등 배달앱 리뷰 한 곳에서 확인
- **직원 관리**: 급여 계산, 출퇴근 관리 기본 기능
- **입금 누락 조회**: 카드사 매출 vs 실제 입금 대조

**가격 정책:**
- 무료: 기본 매출 조회, 알림
- 고급 (4,900원/월): 상권분석 조회, 상세 리포트
- 안심패키지 (20,000원/월): 입금 누락 조회, 세무 알림 강화
- 빠른정산 (50,000원/월): 매출 D+1 입금 서비스
- 플러스 멤버십 (33,000원/월): 모든 프리미엄 기능 + AI 캐시니 월 1,000회

**사용자 선호 기능:** 컴퓨터 미숙자도 매출/비용 한눈에 확인 가능, 배달앱 리뷰 통합 알림, 주변 신규 업체 정보
**사용자 불만:** 광고성 알림 과다 (99%가 광고), 음식점 외 업종 최적화 부족

**데이터 연동:** 카드사 매출 스크래핑, 은행 계좌 연동, 국세청 데이터 수집, 배달앱 API 연동

**시장 현황:** 도입 사업장 300만 돌파 (2026.01 기준), 전체 기능 86개 중 14개에 AI 기술 적용

### 1.2 삼쩜삼 (3o3) — 자비스앤빌런즈

**핵심 기능:**
- **세금 환급 조회**: 5년간 과납한 세금 자동 조회 및 환급 신청 대행
- **종합소득세 신고**: 프리랜서·사업자 대상 간편 신고
- **부가세 신고**: 예상 세액 확인 및 정기신고 지원
- **연말정산 계산기**: 최대 환급 시뮬레이션, 부족한 공제 항목 파악
- **세금 캘린더**: 신고 기한 알림
- **절세 리포트**: AI 기반 절세 방안 제안

**가격 정책:**
- 환급 조회: 무료
- 환급 신청 수수료: 환급액의 10~20% (소액 환급 시 무료)
- 종합소득세 신고: 건별 과금 (정확한 금액은 환급액에 따라 변동)

**사용자 선호:** 3분 만에 환급액 확인, 간단한 UI
**사용자 불만:** 수수료 대비 환급액이 적은 경우 (예: 수수료 32,000원 납부 → 환급 37,000원), 국세청 원클릭(무료) 대비 비싼 수수료

**데이터 연동:** 홈택스 스크래핑 (2025년 정부 규제 강화로 API 전환 압박), 국세청 API

**시장 현황:** 누적 신고 고객 720만 명, 환급 대상자 비율 71%

### 1.3 SSEM (쎔)

**핵심 기능:**
- **AI 셀프 세금신고**: 부가세·종합소득세 약 3분 만에 자동 신고
- **자동 장부 작성**: AI가 거래내역 분류 후 장부 자동 생성
- **절세 솔루션**: 감면·공제 가능한 항목 자동 탐색
- **세무 상담**: 인앱 전문가 상담 연결

**가격 정책:**
- 월 구독료 없음 (사용한 만큼만 과금)
- 종합소득세 신고: 33,000원/건 (매출 규모 무관)
- 부가세 신고: 33,000원/건
- 인건비 신고: 4,400원/인

**사용자 선호:** 매출 규모와 관계없는 균일 가격, 앱스토어 평점 4.8 (최고 수준)
**사용자 불만:** 복잡한 세무 케이스 처리 한계

**데이터 연동:** 홈택스/카드사/은행 스크래핑, 카카오뱅크·현대카드 등 금융사 파트너십

**시장 현황:** 100만+ 가입자, 10년간 서비스 운영

### 1.4 머니핀 (MoneyPin)

**핵심 기능:**
- **AI 자동 장부**: 거래내역 자동 수집 → 계정과목 자동 분류 → 장부 완성
- **세금 신고**: 부가세·종소세·법인세·인건비 신고 일괄 지원
- **AI 절세 진단**: 감면/절세 가능 부분 자동 탐색 및 제안
- **급여 관리**: 급여명세서 자동 발송, 원천세, 4대보험 신고
- **실시간 모니터링**: 손익 현황, 받을 돈/줄 돈 대시보드
- **간편 사업자등록**: 홈택스보다 10배 쉬운 사업자등록 지원

**가격 정책:**
- 기본 기능: 무료
- 세무 대행: 월 80,000원~ (직원 수 기준 산정)

**차별점:** 태그 기반 회계 분류 (차변/대변 몰라도 가능), 복식부기 기반이라 법인도 사용 가능
**사용자 불만:** 부문별 회계 미지원 (제조업/건설업 제한), 인터페이스가 다소 복잡

**데이터 연동:** 국세청/카드사/은행 데이터 자동 수집, 사업자정보 기반 간편 로그인

### 1.5 배달의민족 사장님 (배민사장님)

**핵심 기능:**
- **주문 관리**: 실시간 주문 알림, 주문 확인 → 조리 → 배달 전 과정 관리
- **배달 관리**: 배민라이더스 배정~완료 실시간 추적
- **매출 분석**: 일별/주별/월별 매출, 시간대별 주문 패턴, 인기 메뉴 순위, 평균 주문 금액
- **리뷰 관리**: 고객 리뷰 통합 관리 및 답변
- **메뉴 관리**: 메뉴 추가/수정, 사진·가격·옵션 설정
- **광고 관리**: 배민 내 광고 집행 및 성과 모니터링
- **정산 관리**: 배달 수수료, 광고비 등 정산 내역 확인

**가격 정책:**
- 앱 이용: 무료
- 배달 중개 수수료: 주문당 일정 비율 (가게배달 6.8%, 배민배달 별도)
- 광고비: 별도 과금

**사용자 선호:** 실시간 주문 알림의 안정성, 직관적인 매출 분석
**사용자 불만:** 높은 수수료, 광고 의존도

**데이터 연동:** 배민 자체 생태계 내 완결 (외부 연동 제한적)

### 1.6 토스 사장님 (Toss Business)

**핵심 기능:**
- **매출 정산**: 카드 결제 정산주기 자동 계산, 당일 카드매출·배달 정산액 확인
- **가게 장부**: 매입/매출 구분, 세금계산서 핵심 내용 간편 확인
- **매출 분석 리포트**: 주간/월간 매출 그래프, 날짜별 매출 추이
- **사업자 대출**: 신용대출 갈아타기, 저금리 상품 비교
- **POS 서비스**: 토스 사장님 POS 앱 제공
- **결제 솔루션**: 토스페이먼츠 통합

**가격 정책:**
- 앱 이용: 무료
- 결제 수수료: 토스페이먼츠 기준 (카드 2.0~3.5%)
- POS: 무료 제공 (토스 결제 연동 시)

**사용자 선호:** 깔끔한 UI, 정산 예정일 자동 안내, 금융 서비스 통합
**사용자 불만:** 기능이 캐시노트 대비 제한적

**데이터 연동:** 토스 생태계 내 통합, 카드사 매출 연동, 은행 계좌 연동

### 1.7 네이버 스마트스토어센터

**핵심 기능:**
- **판매 분석**: 카테고리별 판매현황, 상품 조회수 대비 구매 비율, 실시간 분석
- **쇼핑행동 분석**: 유입경로 분석, 고객 탐색 패턴
- **고객 관리**: 고객 세그먼트, 재구매율, 단골 고객 관리
- **마케팅 도구**: 쇼핑라이브 연동, 스토어찜 쿠폰, 리뷰 이벤트
- **AI 추천 시스템**: 고객 맞춤 상품 추천 (일정 등급 이상 판매자)
- **API 데이터솔루션**: 판매분석, 실시간분석, 마케팅분석 데이터 API 제공 (무료 전환)

**가격 정책 (2025년 개편):**
- 스토어 개설: 무료
- 주문관리 수수료: 1.98%~3.63% (매출 규모별 차등)
- 판매 수수료: 1%~3% (유입 경로별 차등)
- 스타트 제로수수료: 신규 판매자 수수료 환급 프로그램
- 분석 도구: 무료 (랭킹, 유입, 리뷰, 검색품질, 수요 데이터)

**사용자 선호:** 강력한 분석 도구 무료 제공, 네이버 검색 노출 연계
**사용자 불만:** 수수료 체계 복잡, 네이버 플랫폼 의존도

**데이터 연동:** 네이버 Commerce API, 쇼핑 인사이트 API, 결제 API

### 1.8 카카오비즈니스

**핵심 기능:**
- **카카오톡 채널**: 친구 관리, 1:1 채팅 상담, 예약·주문·결제 통합
- **카카오모먼트**: 비즈보드, 디스플레이, 동영상, 메시지 광고 집행 플랫폼
- **톡스토어**: 카카오톡 내 간편 쇼핑몰 운영
- **카카오맵 매장관리**: 위치 기반 매장 노출
- **채널 메시지**: 타겟팅 기반 마케팅 메시지 발송

**가격 정책:**
- 카카오톡 채널 개설/운영: 무료
- 메시지 발송: 건당 15원 (CPMS 방식)
- 카카오모먼트 광고: 실시간 입찰 방식 (최소 50원~)
- 톡스토어 수수료: 별도 과금

**사용자 선호:** 카카오톡 생태계 활용 (국민 메신저), 높은 메시지 도달률
**사용자 불만:** 광고 비용 예측 어려움, 경쟁 심화로 단가 상승

**데이터 연동:** 카카오 비즈니스 API, 카카오싱크 (간편가입), 알림톡/친구톡 API

### 1.11 Square Dashboard (해외)

**핵심 기능:**
- **매출 분석**: 실시간 매출 리포트, 캠페인별 성과 분석 (오픈율, 클릭률, 매출 기여도)

## 4. 구체적 구현 방안

### 4.1 세금 캘린더 + 알림 시스템

**벤치마킹 대상:** 삼쩜삼 세금 캘린더, SSEM 신고 안내

**구현 방안:**
- build.up의 기존 로드맵 엔진에 세금 일정 노드 추가
- 사업자 유형(간이/일반/법인)에 따라 자동으로 세금 일정 생성
- 부가세(1/7월), 종소세(5월), 원천세(매월 10일), 4대보험(매월) 등
- 신고 마감 D-30, D-7, D-3, D-1 단계별 알림
- 각 세금 항목에 "준비할 서류" 체크리스트 연동

**기존 시스템 통합:**
```
[로드맵 엔진] → 사업자 등록 단계에서 업종/유형 입력
            → 세금 일정 자동 생성 (워크플로 트리거)
            → 알림 모듈에 스케줄 등록
            → AI 모듈이 준비 상태 진단 ("부가세 신고 준비도 70%")
```

### 4.2 간편 손익 대시보드

**벤치마킹 대상:** 캐시노트 매출 대시보드, 토스 사장님 가게장부, QuickBooks 대시보드

**구현 방안:**
- **카드 기반 UI**: 핵심 지표를 카드 형태로 표시 (오늘 매출, 이번 달 순이익, 현금 잔고)
- **그래프 뷰**: 일별/주별/월별 매출·비용 추이 차트
- **손익 계산**: 매출 - 비용 = 순이익 자동 계산 (수동입력 기반으로 시작)
- **전월 대비**: % 변화량 표시 (Shopify 스타일)
- **목표 대비**: 사업계획서상 목표 매출 대비 달성률 표시

**기존 시스템 통합:**
```
[재무 시뮬레이션 엔진] → 사업계획서 목표 데이터 연동
                     → 실제 입력 데이터와 비교
                     → GAP 분석 자동 제공
                     → AI 모듈이 "매출 목표 대비 15% 부족, 원인 분석" 제공
```

### 4.3 AI 경영 비서 (build.up 코치)

**벤치마킹 대상:** 캐시노트 캐시니, QuickBooks Intuit Assist

**구현 방안:**
- build.up의 기존 AI 모듈을 확장하여 대화형 경영 비서 구현
- **차별화 포인트**: 단순 데이터 조회가 아닌 "창업 코칭" 관점
  - "이번 달 매출이 줄었는데 왜 그럴까요?" → 요인 분석 + 개선 방안
  - "경쟁업체가 새로 생겼는데 어떻게 대응할까요?" → 전략 제안
  - "자금이 부족한데 어떤 지원금을 받을 수 있을까요?" → 정책자금 매칭

**기술 스택:**
```
[LLM 기반 AI 모듈]
  ├── Context: 사용자의 사업계획서 + 재무 데이터 + 로드맵 진행 상황
  ├── RAG: 창업 지식베이스 (세금, 마케팅, 운영 노하우)
  ├── Tool Use: 재무 시뮬레이션 실행, 일정 생성, 할 일 추가
  └── Personalization: 업종/사업 단계/매출 규모별 맞춤 응답
```

### 4.4 매출/비용 자동 수집 및 분류

**벤치마킹 대상:** 캐시노트 매출 통합, 머니핀 AI 자동장부, QuickBooks 자동 분류

**구현 방안 (단계적):**

**Step 1 — 수동입력 최적화 (즉시):**
- 매출/비용 빠른 입력 UI (금액 + 카테고리 + 메모)
- 반복 거래 자동 제안 ("지난달과 같은 임대료 입력할까요?")
- 영수증 사진 → OCR → 자동 입력

**Step 2 — 반자동 수집 (마이데이터 API 활용):**
- 개인사업자 마이데이터 도입 시 (정부 계획 진행 중) API 연동
- 오픈뱅킹 API로 계좌 거래내역 자동 수집
- AI가 거래내역을 카테고리 자동 분류 (머니핀 태그 방식 참고)

**Step 3 — 완전 자동화 (장기):**
- 카드사 API 직접 연동 (마이데이터 라이선스 필요 or 제3자 활용)
- POS 연동으로 개별 거래 단위 매출 수집
- 배달앱/이커머스 정산 데이터 자동 수집

### 4.5 AI 기반 현금흐름 예측

**구현 방안:**

**기존 시스템 통합:**
```
[재무 시뮬레이션 엔진]
  ├── 입력: 과거 매출/비용 데이터 + 고정비 패턴
  ├── 모델: 시계열 예측 (Prophet or 간단한 이동평균)
  ├── 출력: 현금흐름 예측 그래프 + 위험 구간 하이라이트
  └── 연동: AI 비서가 위험 감지 시 선제적 알림 + 대응 방안 제안
```

### 5.2 build.up 대시보드 UX 원칙

1. **"1-3-10 Rule"**: 1초에 현황 파악, 3초에 핵심 인사이트, 10초에 다음 행동 결정
2. **Proactive UX**: AI가 먼저 알림/제안 (사용자가 찾지 않아도)
3. **Progressive Disclosure**: 초보 창업자에게 복잡한 회계 용어 대신 쉬운 말로
4. **Contextual Help**: 각 수치 옆에 "이게 뭔가요?" 터치 시 설명 + 업계 평균 비교
5. **Mobile-First**: 소자본 창업자 대부분 모바일 위주 사용
6. **Dark/Light Mode**: 야간 매장 운영자 배려

## 6. 데이터 연동 전략

### 6.1 연동 방식 비교

| 방식 | 장점 | 단점 | 적용 대상 |
|------|------|------|----------|
| **마이데이터 API** | 합법적, 안정적, 정부 지원 | 라이선스 필요, API 과금 | 은행/카드/보험 데이터 |
| **오픈뱅킹 API** | 표준화, 무료~저비용 | 은행 계좌 한정 | 계좌 잔고/거래내역 |
| **공공데이터 API** | 무료, 합법 | 실시간성 부족 | 상권분석, 사업자 정보 |
| **스크래핑** | 빠른 구현 | 법적 리스크 ↑ (2025 규제 강화) | 비추천 |
| **수동입력 + OCR** | 가장 빠른 구현, 법적 리스크 0 | 사용자 부담 | 초기 MVP |
| **파트너십 API** | 안정적, 깊은 연동 | 사업 개발 필요 | POS사, 배달앱 |

### 6.2 단계별 연동 전략

**Phase 1 — 자체 데이터 (즉시):**
```
- 수동입력 (매출/비용 간편 입력 UI)
- 영수증 OCR (네이버 CLOVA OCR or Google Vision API)
- build.up 내부 데이터 (로드맵 진행, 사업계획서 목표)
```

**Phase 2 — 공공 데이터 (1~3개월):**
```
- 소상공인시장진흥공단 상권정보 API
- 국세청 사업자등록정보 API
- 행정안전부 인구통계 API
- 기상청 날씨 API (매출-날씨 상관분석용)
```

**Phase 3 — 금융 데이터 (3~6개월):**
```
- 오픈뱅킹 API (금융결제원): 계좌 잔고 + 거래내역
- 마이데이터 API (개인사업자 확대 시): 카드 매출 + 보험 등
- BC카드 빅데이터 플랫폼 API: 카드 매출 분석 데이터
```

**Phase 4 — 파트너십 (6~12개월):**
```
- POS 업체 연동 (키오스크코리아, 포스뱅크 등)
- 배달앱 API (배민/요기요/쿠팡이츠 — 파트너 협의 필요)
- 네이버 스마트스토어 Commerce API
- 카카오비즈니스 API
- 세무/회계 솔루션 연동 (SSEM, 머니핀 등과 데이터 교환)
```

### 6.3 마이데이터 2.0 대응 전략

2025년 마이데이터 2.0의 핵심 변화와 build.up의 대응:

| 변화 | build.up 기회 |
|------|-------------|
| 동의 절차 간소화 (2단계→1단계) | 사용자 온보딩 시 금융 데이터 연동 용이 |
| 개인사업자 마이데이터 도입 예정 | 소상공인 매출/비용 데이터 자동 수집 가능 |
| API 과금 체계 도입 | 비용 고려한 선별적 데이터 호출 설계 필요 |
| 대면 영업 허용 | 오프라인 창업 교육과 연계 가능 |

## 7. 핵심 차별화 전략 요약

build.up이 기존 서비스들과 차별화되는 포인트:

### 기존 서비스들의 공통 한계
1. **분절된 경험**: 매출은 캐시노트, 세금은 삼쩜삼, 직원은 시프티 — 앱을 여러 개 써야 함
2. **현재 데이터만 제공**: "지금 매출이 얼마" 만 알려줌, "앞으로 뭘 해야 하는지" 안내 부족
3. **창업 초기 고려 부족**: 대부분 이미 영업 중인 사업장 대상, 창업 준비 단계 무시
4. **수동적 도구**: 사용자가 찾아야 정보 제공, 선제적 코칭 부재

### build.up의 차별화 포지션

```
┌─────────────────────────────────────────────────────┐
│  "로드맵 기반 경영 코치" = 다른 서비스와의 결정적 차이  │
├─────────────────────────────────────────────────────┤
│                                                     │
│  캐시노트 = "오늘 매출 얼마?"     (현재 상태 조회)    │
│  삼쩜삼   = "세금 얼마 돌려받아?"  (단발성 작업)      │
│  build.up = "다음 단계에서 뭘 해야 성공?"             │
│             (과거→현재→미래를 잇는 코칭)              │
│                                                     │
│  핵심 가치 공식:                                     │
│  [로드맵 진행 상황] × [실제 경영 데이터] × [AI 코칭]  │
│  = "당신의 사업이 지금 어디 있고, 다음에 뭘 해야 하는지"│
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 통합 시나리오 예시

**시나리오: 카페 창업 3개월차 사장님**

1. 아침 출근 → 대시보드에서 어제 매출 확인 (캐시노트 수준)
2. AI 코치 알림: "이번 주 매출이 목표 대비 20% 부족합니다. 같은 상권 카페 평균과 비교하면..."
3. AI 코치 제안: "로드맵 단계상 '단골 확보' 시기입니다. 스탬프 카드 도입을 추천드립니다."
4. 할 일 자동 생성: "□ 스탬프 카드 디자인 □ 단골 혜택 설정 □ 카카오톡 채널 안내 배너 제작"
5. 부가세 D-14 알림: "부가세 준비 체크리스트 3/7 완료. 나머지 4개를 이번 주에 끝내세요."
6. 월말 리포트: "이번 달 손익: +₩180만원 (목표 대비 90% 달성). 다음 달 현금흐름 예측: 안전"

이것이 build.up만이 제공할 수 있는 **"창업 동반자"** 경험입니다.

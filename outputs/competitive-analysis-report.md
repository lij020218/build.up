## 1. 한국 국내 경쟁사 심층 분석

### 1.1 캐시노트 (한국신용데이터)

**카테고리**: 운영 단계 매출/경영 관리
**사용자 규모**: 300만 사업장 도입
**가격**: 기본 무료 / 스탠다드 멤버십 월 33,000원

| 기능 | 상세 |
|------|------|
| 카드 매출 입금 알림 | 실시간 문자/카카오톡 알림 |
| 하루 매출 통계 | 일별/월별 매출 집계 |
| 입금 누락 확인 | 카드사별 입금 예정/실제 비교 |
| 고객 재방문 분석 | 재방문율, 고객 세그먼트 |
| 세무서 대응 알림 | 부가세, 종합소득세 일정 |
| AI 경영 비서 '캐시니' | 매출/입금 예상, 상권 비교, 리뷰 분석 |
| 대출 비교 | 사장님 전용 대출 상품 비교 |
| 전자 세금계산서 | 발급 대행 서비스 |
| 데이터랩 | 업종/상권 데이터 분석 |

**강점**: 한국 소상공인 사실상의 표준 서비스. PG사/카드사 연동으로 실시간 매출 데이터 확보. 무료 기본 서비스로 대규모 사용자 확보.

**약점**: 창업 준비 과정 지원 미흡(2025년에 '창업준비' 기능 출시했으나 제한적). 프랜차이즈 비교, 인허가 가이드, 인테리어 가이드 없음. 업종별 맞춤 로드맵 없음.

**build.up 대비**: 운영 단계 매출 관리에서는 캐시노트가 압도적. 하지만 창업 준비부터 운영까지 전 과정을 커버하지 못함.

---

### 1.2 마이프차 (MyFranchise)

**카테고리**: 창업 준비 단계 - 프랜차이즈 전문
**가격**: 기본 무료 / 마이프차 지도 유료 구독

| 기능 | 상세 |
|------|------|
| 프랜차이즈 비교 | 공정위 등록 1만여 개 브랜드 정보 |
| 정보공개서 분석 | 창업비용, 월평균 매출, 가맹점 수 차트화 |
| 상권 분석 (마이프차 지도) | 프랜차이즈 현황, 주변 시설, 로드뷰 |
| 창업 상담 연결 | 브랜드 담당자 직접 상담 |
| 파트너 부동산 | 인증 부동산을 통한 점포 매칭 |
| 마이프차 매거진 | 창업 정보 콘텐츠, 브랜드 인터뷰 |

**강점**: 프랜차이즈 비교 분야에서 한국 1위. 정보공개서 데이터 시각화 우수. 상권 분석 + 부동산 연결까지 제공.

**약점**: 프랜차이즈 창업에만 특화되어 독립 창업자 지원 부족. 개업 이후 운영 관리 기능 전무. 인허가/보험/인테리어 가이드 없음. 재무 시뮬레이션 없음.

**build.up 대비**: 프랜차이즈 비교에서 마이프차가 더 깊음(1만 개 브랜드). 하지만 build.up은 프랜차이즈 + 독립 창업 모두 지원하고, 창업 이후 운영 단계까지 연결됨.

### 1.3 토스 사장님 / 토스 비즈니스

**카테고리**: 결제 + POS + 간편 매출 관리
**가격**: POS 하드웨어 비용 + 결제 수수료

| 기능 | 상세 |
|------|------|
| POS 시스템 | 주문/테이블/예약 관리 |
| 결제 수단 | 모든 결제수단 통합 (카드, 현금, 간편결제) |
| 실시간 매출 보기 | 매출 리포트, 달력 뷰 |
| 포인트/스탬프 적립 | 자체 고객 로열티 프로그램 |
| 키오스크 모드 | 무인 주문 지원 |
| 토스 비즈니스 앱 | 쇼핑 광고 현황, 주문 관리 |

**강점**: 토스 생태계 내 원스톱 결제 + 매출 관리. UX/UI 우수. 젊은 사장님 사이에서 빠르게 성장 중.

**약점**: POS/결제에 집중되어 있어 경영 관리 깊이 부족. 창업 준비 지원 없음. 프랜차이즈 비교, 상권 분석, 인허가, 인테리어 가이드 없음.

**build.up 대비**: 토스는 결제/POS 영역 전문. build.up과 경쟁 영역이 최소한이나, 운영 단계에서 일부 겹침(매출 관리).

---

### 1.4 배민 사장님 (배달의민족)

**카테고리**: 배달/외식업 전문 운영 관리
**가격**: 배달 수수료 기반

| 기능 | 상세 |
|------|------|
| 주문 관리 | 가게배달/알뜰배달/한집배달 구분 관리 |
| 메뉴 관리 | 셀프서비스로 메뉴 추가/수정 |
| 임시중지 | 영업 일시 중단 기능 |
| 배민외식업광장 | 외식업 트렌드, 장사 노하우, 정책 정보 |
| 리뷰 관리 | 고객 리뷰 응답/관리 |
| 광고 관리 | 배민 플랫폼 내 광고 운영 |
| 배민상회 | 식자재 구매 플랫폼 |

**강점**: 외식업(특히 배달) 분야에서 압도적 시장 점유율. 주문-배달-리뷰-식자재까지 외식업 생태계 구축.

**약점**: 배달 플랫폼에 종속. 외식업 외 업종 지원 없음. 창업 준비 과정 지원 없음. 재무/세무/인사 관리 없음.

**build.up 대비**: 외식업 배달 주문 관리에 특화. build.up은 외식업 포함 13개 이상 업종을 포괄하며, 배달 플랫폼에 종속되지 않는 독립적 경영 관리 제공.

### 1.5 네이버 스마트플레이스

**카테고리**: 온라인 노출/마케팅 관리
**가격**: 기본 무료 / 네이버 광고 비용 별도

| 기능 | 상세 |
|------|------|
| 업체 정보 관리 | 영업시간, 메뉴, 사진, 동영상 |
| 검색/지도 노출 | 네이버 검색 시 지도에 업체 표시 |
| 예약/주문 | 네이버 예약/주문 시스템 연동 |
| 리뷰 관리 | 고객 리뷰 직접 관리/응답 |
| 통계 | 방문자, 조회수 분석 |
| 가게 소식 | 이벤트, 신메뉴 등 소식 게시 |

**강점**: 한국 소비자 검색의 시작점인 네이버에서의 노출 관리. 기본 무료. 예약/주문 시스템 내장.

**약점**: 네이버 플랫폼 내 노출 관리에만 국한. 실제 경영 관리(재무, 인사, 재고) 불가. 창업 과정 지원 없음.

**build.up 대비**: 마케팅/온라인 노출 영역만 담당. build.up의 경쟁 영역이 아니라 보완 관계에 가까움.

### 1.6 자비스 (Jobis)

**카테고리**: 세무/회계 전문
**가격**: AI 경리 월 33,000원 / 세무대행 월 80,000원~

| 기능 | 상세 |
|------|------|
| AI 경리 | 자동 회계관리, 거래내역 분류 |
| 세무 대행 | 부가세, 종합소득세, 법인세 신고 |
| 급여 관리 | 급여 계산, 원천세 처리 |
| 영수증 관리 | 자동 인식/분류 |
| 재무 현황 분석 | 대시보드, 리포트 |
| 법무 지원 | 기본 법무 서비스 |

**강점**: AI 기반 경리 자동화. 세무사 없이도 기본 세무 처리 가능. 소규모 사업자에게 비용 효율적.

**약점**: 세무/회계에만 집중. 창업 준비, 상권 분석, 인허가 등 지원 없음. 업종별 맞춤 기능 없음.

**build.up 대비**: 세무/회계 깊이에서 자비스가 우위. build.up은 세금 캘린더와 기본 재무 분석을 제공하지만, 세무대행까지는 하지 않음. 상호 보완적.

### 1.7 얼마 (OLMA)

**카테고리**: 소상공인 종합 경영 플랫폼
**가격**: 기본 무료 / 유료 기능 별도

| 기능 | 상세 |
|------|------|
| 매출/매입 관리 | AI 자동 데이터 수집 |
| 고객 관리 | 거래처 외상관리 |
| 급여/근태 관리 | 급여 계산, 근태 기록 |
| 통합 계정 관리 | 계좌 입출금 관리 |
| 전자 문서 발급 | 세금계산서 발행 |
| 세금 신고 | 기본 세금 신고 지원 |
| 사업 리포트 | 한눈에 보는 사업 흐름 |

**강점**: 매출/매입/급여/세금을 하나의 앱에서 관리 가능. AI 기반 자동 데이터 수집.

**약점**: 창업 준비 단계 지원 없음. 업종별 맞춤화 부족. 프랜차이즈 비교, 상권 분석, 인허가, 인테리어 가이드 없음.

**build.up 대비**: 운영 단계 경영 관리에서 유사한 기능(매출, 비용, 급여). 하지만 build.up은 창업 준비 전 과정을 포함하고 업종별 맞춤 기능을 제공.

---

### 1.8 공공 서비스: 소상공인24 / K-Startup / 상권 분석 시스템

| 서비스 | 주요 기능 | 한계 |
|--------|-----------|------|
| **소상공인24 (SEMAS)** | 정책자금, 교육, 컨설팅 연결 | 앱 사용성 매우 열악, 호환성 문제, 유지보수 방치 |
| **K-Startup** | 창업지원사업 공고, 단계별 정보 | 정보 나열 중심, 실행 도구 없음 |
| **소상공인365 상권분석** | 업종별 밀집도, 상권 성장성 등급 | 무료지만 UX 열악, 모바일 최적화 부족 |
| **우리마을가게 (서울시)** | 골목상권 분석, 유동인구, 매출 | 서울 한정, 타 지역 미지원 |
| **소상공인 스마트상점** | AI/디지털 기술 도입 비용 지원 | 보조금 지원일 뿐 직접적 도구 아님 |

**공공 서비스의 공통 문제점**:
- 4억원을 들인 소상공인 전용 앱이 사실상 방치된 사례 보도
- 같은 기관에서 만든 앱끼리도 호환되지 않아 별도 계정 필요
- 홈페이지를 그대로 모바일에 옮긴 수준의 기능성
- 출시 이후 유지/운영비 예산 미투입

**build.up 대비**: 공공 서비스의 데이터(상권, 정책자금 정보)는 가치 있으나, UX와 통합성이 극히 부족. build.up이 이 데이터를 통합하여 사용자 친화적으로 제공하면 강력한 차별점이 됨.

### 1.9 큐플레이스 (Qplace)

**카테고리**: 상가 인테리어 비교견적 전문
**실적**: 견적 15,000건, 매장 오픈 1,500개, 거래액 600억원

| 기능 | 상세 |
|------|------|
| 비교견적 | 디자인/예산/일정/지역 조건 맞춤 업체 매칭 |
| 업체 검증 | 400여 개 인테리어 업체 실적/후기 정보 |
| 안심보증제 | 공사 중 사고 보증 |
| 인테리어 가이드 | 업종별 인테리어 기본 가이드 |

**build.up 대비**: 인테리어 견적/시공에 특화. build.up은 업종별 인테리어 "가이드"(레이아웃, 필수 설비, 비용 범위)를 제공하지만, 실제 업체 매칭/견적은 하지 않음. 향후 큐플레이스와 제휴 가능성 있음.

## 2. 글로벌 경쟁사 심층 분석

### 2.1 Shopify

**카테고리**: 이커머스 + 온라인 스토어 올인원
**가격**: Basic $39/월, Shopify $105/월, Advanced $399/월

| 기능 | 상세 |
|------|------|
| 온라인 스토어 구축 | 드래그앤드롭 웹사이트 빌더 |
| 결제 처리 | Shop Pay, 모든 주요 결제수단 |
| 재고 관리 | 멀티채널 재고 동기화 |
| 마케팅 도구 | SEO, 이메일 마케팅, 소셜미디어 |
| AI 도구 (Shopify Magic) | 상품 설명 자동 생성, 메타데이터 최적화 |
| 세금 자동 계산 | 지역별 세금 자동 적용 |
| 창업 가이드 | 이커머스 창업 단계별 가이드 콘텐츠 |

**강점**: 470만 개 이상 비즈니스 사용. 이커머스 분야 글로벌 1위. 앱스토어를 통한 무한 확장.

**약점**: 온라인 커머스에 특화. 오프라인 매장 경영 관리 미흡. 한국 소상공인 규제/인허가 비지원. 한국어/한국 시장 맞춤화 부족.

---

### 2.2 Square

**카테고리**: 결제 + POS + 올인원 비즈니스 관리
**가격**: 기본 무료 / 결제 수수료 2.6%+$0.10

| 기능 | 상세 |
|------|------|
| POS 시스템 | 업종별 특화 POS (레스토랑, 소매 등) |

## 4. 갭 분석: build.up만의 차별점

### 4.1 전 세계적으로 비어있는 영역

현재 한국 및 글로벌 시장에서 **"창업 준비 전 과정 + 운영 관리"**를 하나의 플랫폼에서 제공하는 서비스는 사실상 존재하지 않는다.

```
시장 구조 (현재):

[창업 준비]          [공백]          [운영 관리]
마이프차 ─────────── ??? ──────────── 캐시노트
K-Startup                             토스 사장님
공공 상권분석                          얼마
                                       자비스
                                       배민 사장님

[build.up의 포지션]
마이프차 ─────── build.up ──────── 캐시노트
         전 과정을 하나로 연결
```

### 4.2 build.up의 5가지 핵심 차별점 (Blue Ocean)

**1. 업종별 단계별 창업 로드맵 (14~20단계)**
- 경쟁사: 없음. K-Startup은 일반적 정보 나열만 함
- 차별점: 업종(카페, 음식점, 미용실 등)에 따라 맞춤화된 로드맵

**2. 인허가/면허 체크리스트**
- 경쟁사: 없음. 정부 사이트에서 개별 검색해야 함
- 차별점: 업종별 필요 인허가를 체크리스트로 정리, 진행 추적 가능

**3. 업종별 인테리어 가이드**
- 경쟁사: 없음. 큐플레이스는 견적 서비스, 오늘의집은 주거 인테리어
- 차별점: 업종(카페, 음식점, 미용실)별 레이아웃, 필수 설비, 비용 범위 가이드

**4. 예산 기반 입지 필터링**
- 경쟁사: 마이프차 상권분석은 프랜차이즈 중심, 공공서비스는 예산 필터 없음
- 차별점: 보유 자본 입력 시 가능한 지역/상권을 자동 필터링

**5. 창업-운영 연결 (Seamless Transition)**
- 경쟁사: 없음. 창업 앱과 운영 앱이 완전히 분리됨
- 차별점: 창업 단계에서 설정한 재무 계획이 운영 단계 대시보드로 자연스럽게 이어짐

## 6. 전략적 시사점

### 6.1 경쟁 포지셔닝 요약

```
                    창업 준비 깊이
                         |
              마이프차    |    build.up
              (프랜차이즈)|    (전 업종)
                         |
  ─────────────────────────────────────── 운영 관리 깊이
              네이버      |    캐시노트/얼마
              스마트플레이스|    토스 사장님
                         |    자비스
                         |
```

**build.up은 우측 상단 = "창업 준비 깊이 + 운영 관리 깊이" 모두 높은 유일한 플레이어**

### 6.2 경쟁 우위 유지를 위한 권장 전략

**1. 데이터 해자 (Data Moat) 구축**
- 공공 상권 데이터 + 정보공개서 데이터를 build.up 내에서 최고 수준으로 시각화
- 사용자들의 실제 창업 비용/기간 데이터 축적 (시간이 지날수록 경쟁력 강화)

**2. 생태계 파트너십**
- 캐시노트: 실시간 매출 데이터 연동 (API)
- 큐플레이스: 인테리어 견적 연결
- 자비스: 세무 대행 연결
- 네이버 스마트플레이스: 온라인 노출 가이드 연결
- 배민상회: 식자재 거래처 연결

**3. "졸업 없는 플랫폼" 전략**
- 창업 준비 --> 개업 --> 운영 --> 성장 --> 2호점까지 모든 단계에서 이탈하지 않는 구조
- 각 단계 전환 시 기존 데이터가 다음 단계로 자연스럽게 이동

**4. 위험 요소 모니터링**
- 캐시노트의 "창업준비" 기능 확장 동향 주시 (300만 사업장 기반)
- 마이프차의 운영 관리 영역 확장 가능성
- 토스의 사장님 생태계 확장 속도 (앱인토스 플랫폼)

### 6.3 build.up의 핵심 경쟁 메시지

> **"창업의 첫 생각부터 매일의 경영까지, 하나의 앱에서."**

현재 소상공인은 창업 준비에 마이프차/K-Startup, 운영에 캐시노트/얼마, 세무에 자비스, 마케팅에 네이버 스마트플레이스를 각각 사용해야 한다. build.up은 이 모든 여정을 하나의 플랫폼에서 업종별로 맞춤 제공하는 유일한 서비스이다.
